paseo-bm · New mission and "+ Add" — choose projects, not workspaces — mockup for the owner's approval (2026-10-21, draft 1)

Replaces the "Repositories" chips of artboard E (missions-screen.html) and the "+ Add" picker of the mission page. Today the chips list Paseo workspaces by their titles, which are often a chat's title ("Greet user and await task") and repeat one repository once per workspace ("Paseo-BM Plugin" and "Review Paseo agent workflow…" are both paseo-bm). Now there is one row per Paseo project, named as Paseo's sidebar names it (its folder name, or the name you gave the project in Paseo), with its folder underneath so two similar names are told apart. Choosing a project means its main checkout; a mission's own worktrees and paseo-bm's homes are never listed. Everywhere a mission names a repository (the charter, Repositories, Workers by repository, memory) uses the same project name. Nothing else on the form changes. New parts have a dashed outline.
